# troubleshooting-guide Specification

## Purpose
Defines the content of `docs/troubleshooting.md` — troubleshooting guide for common grubble issues.

## Requirements

### Requirement: documents common errors and fixes
The file SHALL document the following errors and their fixes: "Author identity unknown", "grubble: command not found", no version bump on merge, invalid config file, package file not found, push fails on protected branches (GH006), auto-merge stuck in "Waiting for approval", "Invalid format" in GITHUB_OUTPUT, and "head branch is not up to date with the base branch".
